# تست بازطراحی مدیریت مدیاها (فقط smc-server)

این اصلاحات تنها روی `develop` ثبت شده‌اند. `main`، `.env` و سرور اصلی تغییری نکرده‌اند.

## دریافت و راه‌اندازی بدون حذف فایل‌های قبلی

**فایل‌های قبلی را پاک نکنید.** نسخه جدید، برای تصاویر و ویدیوهای قبلی هنگام اولین نمایش Thumbnail مجزا تولید می‌کند و فایل‌های اصلی را تغییر نمی‌دهد.

```bash
hostname
cd /root/portal
git status -sb
git pull --ff-only origin develop
docker compose up -d --no-deps --build app
docker compose ps
docker logs --tail 60 node_app
docker exec node_app node --test test/invoice-media.test.js
docker exec node_app magick -list format | grep -E 'HEIC|JPEG|PNG|WEBP'
docker exec node_app ffmpeg -version | head -1
```

پس از راه‌اندازی، صفحه مرورگر سرور تست را با `Ctrl + F5` بارگذاری کنید.

## تست صفحه مدیریت فاکتور

- در ستون تکنسین، سطر جدید دو قسمت افقی دارد: «سریال‌ها» در سمت راست و «فایل‌ها» در سمت چپ.
- دکمه «مدیریت سریال‌ها» باید مانند قبل کار کند؛ دکمه «مدیریت فایل‌ها» پنجره جدید را باز می‌کند.
- در پنجره فایل‌ها، سمت راست پنل آپلود و سمت چپ مرور فایل‌هاست.
- آپلود در دو نوع «فایل فاکتور» و «فایل سرور» با انتخاب سریال انجام می‌شود.
- فهرست فایل‌ها تب فاکتور/سرور دارد؛ گروه‌های سریال همان ترتیب ثبت سریال‌ها را حفظ می‌کنند.
- تصویر و ویدیو باید Thumbnail واقعی داشته باشند؛ اسناد PDF/Office نماد پسوند فایل را نشان دهند.
- برای تصاویر و ویدیوهای قدیمی ایجاد Thumbnail ممکن است در اولین نمایش چند ثانیه طول بکشد.
- تصویر بزرگ در پیش‌نمایش ابتدا باید کاملاً داخل صفحه جا شود و فقط با زدن «اندازه واقعی (۱۰۰٪)» بزرگ شود.
- دانلود یک فایل و ZIP کل سریال و ZIP کل فاکتور را تست کنید.
- با حساب کارشناس فروش، فهرست و دانلود در دسترس باشد اما پنل آپلود و حذف فایل نمایش داده نشود.

## داده و فایل‌ها

- فایل اصلی بدون تغییر در `/root/portal-media` نگه داشته می‌شود. Thumbnail جداگانه و کم‌حجم است.
- ظرفیت هر فایل ۵۰۰ MiB و سهمیه کل ۱۰۰ GiB است؛ این مقادیر تغییر نکرده‌اند.
- PostgreSQL فقط متادیتا و مسیرهای فایل‌ها را نگه می‌دارد؛ بکاپ باید شامل `/root/portal-media` هم باشد.
- برای فایل‌های HEIC/TIFF پیش‌نمایش کوچک در گالری ایجاد می‌شود؛ مشاهده تمام‌اندازه در مرورگر ممکن است پشتیبانی نشود، اما دانلود اصل فایل امکان‌پذیر است.

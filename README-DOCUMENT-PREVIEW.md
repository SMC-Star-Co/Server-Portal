# نمایش اسناد و ویدیو
PDF.js 6.5.438 در زمان Build نصب می‌شود و در شبکه داخلی از /pdfjs/ سرو می‌شود. PDF اصلی با Range و احراز هویت خوانده می‌شود؛ صفحه و لایه متن در مرورگر رندر می‌شوند. PDF اسکن‌شده بدون متن قابل انتخاب نیست. Word/Excel/PowerPoint/RTF/ODT/ODS با LibreOffice در کانتینر document جداگانه، بدون اتصال اینترنت مستقیم و بدون دسترسی به فایل‌های اصلی، به PDF موقت تبدیل می‌شوند. پیش‌نمایش Office تا 64MiB ورودی/خروجی و یک تبدیل هم‌زمان محدود است؛ چیدمان ممکن است با Office اصلی تفاوت داشته باشد. TXT/LOG/CSV تا 4MiB به صورت متن نمایش داده می‌شوند. اصل فایل‌ها تغییر نمی‌کند.
ویدیو: آیکن صدا، تمام صفحه واقعی با Fullscreen API (در صورت عدم پشتیبانی، تمام پنجره)، کنترل‌های محوشونده در حالت پخش. در حالت توقف، کنترل‌ها باقی می‌مانند.
استقرار: docker compose up -d --build app document ; docker compose restart web ; Ctrl+F5. نصب اولیه نیازمند دسترسی به npm و مخازن Alpine است.

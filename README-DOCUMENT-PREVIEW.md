# نمایش اسناد و ویدیو
PDF.js 6.5.438 در زمان Build نصب می‌شود و در شبکه داخلی از /pdfjs/ سرو می‌شود. PDF اصلی با Range و احراز هویت خوانده می‌شود؛ صفحه و لایه متن در مرورگر رندر می‌شوند. PDF اسکن‌شده بدون متن قابل انتخاب نیست. Word/Excel/PowerPoint/RTF/ODT/ODS با LibreOffice در کانتینر document جداگانه، بدون اتصال اینترنت مستقیم و بدون دسترسی به فایل‌های اصلی، به PDF موقت تبدیل می‌شوند. پیش‌نمایش Office تا 64MiB ورودی/خروجی و یک تبدیل هم‌زمان محدود است؛ چیدمان ممکن است با Office اصلی تفاوت داشته باشد. TXT/LOG/CSV تا 4MiB به صورت متن نمایش داده می‌شوند. اصل فایل‌ها تغییر نمی‌کند.
ویدیو: آیکن صدا، تمام صفحه واقعی با Fullscreen API (در صورت عدم پشتیبانی، تمام پنجره)، کنترل‌های محوشونده در حالت پخش. در حالت توقف، کنترل‌ها باقی می‌مانند.
استقرار: docker compose up -d --build app document ; docker compose restart web ; Ctrl+F5. نصب اولیه نیازمند دسترسی به npm و مخازن Alpine است.

## اصلاح مسیر بارگذاری PDF و جابه‌جایی فایل‌ها
فایل PDF کوچک (تا 16MiB) با apiFetch به صورت بایت خوانده می‌شود و به PDF.js داده می‌شود، نه با باز کردن URL فایل. PDF بزرگ با درخواست‌های Range و PDFDataRangeTransport خوانده می‌شود. در صورت پاسخ نامعتبر (از جمله 204)، مسیر دانلود امن با درخواست fetch و بدون باز کردن لینک در مرورگر استفاده می‌شود. امضای PDF، طول پاسخ و Content-Range بررسی می‌شوند. فلش‌های چپ/راست در سربرگ و کلیدهای کیبورد، فایل‌های گروه جاری را با ترتیب شماره آپلود مرور می‌کنند؛ تصویر، ویدیو و سند در یک فهرست هستند. در صورت عدم پشتیبانی از فرمت، پیام نمایش داده می‌شود و دانلود ناخواسته انجام نمی‌شود.

## جلوگیری از دریافت ناخواسته توسط IDM
نمایش اسناد در مرورگر فقط از POST احراز هویت‌شده document-data با Content-Type: application/json استفاده می‌کند. PDF به‌صورت قطعه‌های Base64 حداکثر 1MiB همراه با نسخه و طول فایل خوانده می‌شود؛ هیچ لینک دانلود یا پاسخ application/pdf در مسیر نمایش به مرورگر داده نمی‌شود. Office نیز به صورت JSON Base64 و متن ساده به صورت JSON ارسال می‌شود. دانلود صریح فایل اصلی همچنان از دکمه دانلود انجام می‌شود. این تغییر احتمال مداخله دانلودمنیجر را کاهش می‌دهد؛ رفتار افزونه خارجی در محیط واقعی باید بررسی شود.

# پخش ویدیو در مدیریت فایل
- رابط پخش محلی، بدون CDN یا وابستگی خارجی؛ رمزگشایی ویدیو با مرورگر.
- مسیر احراز هویت‌شده video-preview برای دریافت لینک پخش اصلی؛ Range از نوع تکی، پاسخ 206 و 416، پشتیبانی از درخواست HEAD و ETag.
- لینک پخش ۳۰ دقیقه اعتبار عدم فعالیت دارد و در Range بعدی تمدید می‌شود، حداکثر چهار ساعت. برای دانلود و فایل‌های دیگر همان لینک قبلی استفاده می‌شود.
- فقط در صورت خطای کدک/رمزگشایی مرورگر، نسخه سازگار MP4 H.264/AAC تا 720p به شکل خودکار آماده می‌شود؛ اصل فایل تغییر نمی‌کند. تبدیل زنده انجام نمی‌شود.
- یک تبدیل هم‌زمان در هر فرایند app، دو رشته FFmpeg، زمان حداکثر ۱۵ دقیقه، سقف هر نسخه ۵۰۰ MiB، فضای کش جداگانه حداکثر ۲ GiB و کنترل فضای آزاد. کش در /app/media/.video-preview روی همان mount قرار دارد؛ نسخه‌های قابل حذف قدیمی در زمان آماده‌سازی بعدی پاک می‌شوند. پس از حذف یا جایگزینی اصل، نسخه سازگار قبلی پاک می‌شود. اگر محدودیت‌ها اجازه ندهند، دانلود اصل همچنان ممکن است.
- رابط ساده: علامت پخش/توقف، نوار زمان، زمان جاری/کل و کنترل صدا. هیچ دکمه‌ای برای تبدیل، دانلود اصلی، بارگذاری مجدد، سرعت، تمام‌صفحه یا جلو/عقب ده ثانیه‌ای در پلیر وجود ندارد. دانلود اصل از کارت فایل انجام می‌شود.
- تست: docker exec node_app node --test test/invoice-media.test.js test/video-preview.test.js
- در صورت نصب نسخه بک‌اند دارای video-preview، بعد از دریافت اصلاح رابط کاربری: docker compose restart web ؛ Ctrl+F5. برای اولین نصب سیستم پخش: docker compose up -d --build app.
